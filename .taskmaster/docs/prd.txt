# MLCC Dashboard - Page Recreation PRD

## Project Context

This is a Next.js application (using Pages Router) that serves as a community dashboard for MLCC (Maple Leaf Community Council) coordinators. The application uses:

- **Next.js 15** with Pages Router architecture
- **Supabase** as the backend database and authentication provider
- **Relume UI components** (@relume_io/relume-ui) for UI components including Table, Button, Input, Pagination, Breadcrumb, and other design system components
- **Tailwind CSS** with custom color palette (primary green tones, cream backgrounds)
- **TypeScript** for type safety

The application needs to be rebuilt from scratch as the current implementation is failing. Focus on functionality and user experience, not complex setup details.

## Application Structure

The application has a consistent layout structure:
- **Sidebar navigation** with links to: Dashboard, Neighbors, Routes, Businesses
- **AdminLayout** wrapper component that provides consistent page structure
- **Topbar** component for page headers with search and action buttons
- **FilterTabs** component for filtering content
- **Toast notifications** for user feedback

## Common Components and Patterns

### Layout Components
- **AdminLayout**: Wraps all pages, provides consistent structure with header and content areas
- **Sidebar**: Navigation sidebar with links to main pages, shows active state
- **DashboardLayoutContainer**: Container for dashboard-specific layouts

### Common UI Components
- **Topbar**: Page header with title, search, and action buttons
- **FilterTabs**: Tab-based filtering with badge counts
- **Table**: Use Relume Table components (Table, TableHeader, TableBody, TableRow, TableCell, TableHead)
- **Button**: Use Relume Button component
- **Input**: Use Relume Input component for search
- **Modal**: Custom modal component for forms
- **Toast**: Toast notifications for success/error messages
- **CopyableText**: Component for copyable text (emails, etc.)
- **Badge**: Status badges
- **PageHeader**: Relume PageHeader component (alternative to Topbar)
- **GroupedTable**: Relume GroupedTable component for grouped data
- **StackedTable**: Relume StackedTable component for stacked layouts

### Data Fetching Pattern
- Use custom hooks (usePeople, useBusinesses, useRoutes, useDashboard) that:
  - Fetch data from Supabase
  - Handle loading states
  - Handle error states
  - Provide refetch capabilities
- Use Supabase client from `@/lib/supabaseClient` for client-side queries
- Use serverSupabase from `@/lib/serverSupabase` for server-side queries (getServerSideProps)

### Styling
- Use Tailwind CSS with custom color palette
- Primary colors: green tones (#6b8e23, etc.)
- Cream backgrounds for cards and sections
- Consistent spacing and typography

## Technical Requirements

1. **Next.js Pages Router**: All pages should be in the `pages/` directory
2. **TypeScript**: All components and pages should be typed
3. **Supabase Integration**: 
   - Client-side queries use `supabaseClient`
   - Server-side queries use `serverSupabase`
   - Handle Supabase errors gracefully
4. **Relume Components**: Use Relume UI components where applicable, especially for tables and forms
5. **Responsive Design**: Ensure pages work on mobile and desktop
6. **Loading States**: Show loading indicators while fetching data
7. **Error Handling**: Display user-friendly error messages
8. **Toast Notifications**: Use ToastProvider for user feedback on actions

## Success Criteria

- All pages render without errors
- Data loads from Supabase correctly
- Search and filtering work as expected
- Detail cards/sidebars open and close properly
- Forms can add new records to Supabase
- Loading and error states display appropriately
- Navigation between pages works correctly
- Responsive design works on different screen sizes
